## Merge decision

The TokenLink source is ready for normal code review and merge: automated tests,
formatting, privacy checks, firmware build/tests, and the relocatable Mac archive
all pass. The Quick Start now gives honest source paths for users with and
without a C152.

The public v0.2 release is not ready to announce as a zero-tool install. Before
publishing it:

1. Flash and smoke-test the exact firmware release candidate on the confirmed
   C152 port; record the result here.
2. Merge/tag the matching `codex-micro-stopwatch` source and publish a documented
   firmware artifact or keep the source-build requirement explicit.
3. Build TokenLink with a Developer ID identity, notarize it, and publish the app
   archive plus SHA-256 checksum in a GitHub Release.
4. Either add an Intel artifact/universal build or label the first binary release
   Apple-Silicon-only.
5. Observe the hosted CI result after pushing; a local reproduction does not
   substitute for the remote workflow.
