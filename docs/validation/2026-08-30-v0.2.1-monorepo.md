# TokenLink v0.2.1 Monorepo Validation — 2026-08-30

This report covers the migration of the default wireless M5Stack StopWatch C152
firmware into TokenLink. Automated evidence and physical-device evidence remain
separate; pending rows are updated only after the corresponding observation.

## Release decision

The single-repository source/build/package path is automated and reproducible.
The final `e155c5d` C152 flash, installed `app.tokenlink` candidate, explicit
Bluetooth rebind, protocol-v2 sync, C04 refresh, physical UI, reconnect, and
session-focus acceptance all passed. The remaining publication gates are the
TokenLink-only public review/merge flow, hosted CI on the final commit, and the
tag-triggered release workflow. The 24-hour power soak remains follow-up evidence
and is not represented as complete.
