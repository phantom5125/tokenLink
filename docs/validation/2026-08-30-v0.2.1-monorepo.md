# TokenLink v0.2.1 Monorepo Validation — 2026-08-30

This report covers the migration of the default wireless M5Stack StopWatch C152
firmware into TokenLink. Automated evidence and physical-device evidence remain
separate; pending rows are updated only after the corresponding observation.

## Release decision

The single-repository source/build/package path is automated and reproducible,
and the explicit current-working-tree C152 flash and boot regression passed. A
live v2 sync also passed against the previously installed legacy-ID app. The
v0.2.1 tag and release remain blocked on the current `app.tokenlink` explicit
rebind, end-to-end quota/C04/session-focus retest, final commit/rebuilt artifact,
hosted CI, and TokenLink-only review/merge flow.
