# TokenLink 0.3.0

TokenLink 0.3.0 expands the Mac Cost Center into a private local Usage & Cost
workspace and hardens the Mac-to-StopWatch onboarding path. Stable Mac releases
are also published through the project-owned Homebrew tap.

## Highlights

- Attributes local Codex, Claude, and Kimi usage by project, model, reasoning
  effort, and privacy-safe Session without retaining prompts, replies, tool
  output, full paths, or raw Session identifiers.
- Adds a GitHub-style activity calendar, hourly distribution, prior-period
  comparison, estimated active time, custom date ranges, and bounded 400-day
  incremental history.
- Keeps token, cache, API-equivalent cost, pricing coverage, and active-time
  values separately inspectable instead of reducing the Cost Center to money.
- Uses `assets/branding/logo-mark-light.png` across Finder, menu bar, menu panel,
  notifications, and the generated ICNS.
- Loads SwiftPM resources from the standard app Resources directory and
  cold-starts the mounted DMG during release validation.
- Lets a new Mac complete quota pairing before the optional Session command
  channel finishes enabling, and advances the matching firmware bond migration
  for previously prepared watches.

## Homebrew

The stable Release workflow publishes the exact DMG version and SHA-256 to the
project-owned tap after auditing and installing the generated cask:

```bash
brew install --cask phantom5125/tap/tokenlink
```

The Release workflow appends the actual macOS distribution identity to these
notes. Until donor funding provides an Apple Developer Program identity, the
community DMG is ad-hoc signed rather than Apple-notarized and macOS may require
explicit first-launch approval.

## Assets

- `TokenLink-0.3.0.dmg` and `.dmg.sha256`: Universal 2 Mac app with an
  Applications shortcut, resource cold-start verification, and an identity
  label generated from the release workflow.
- `TokenLink-StopWatch-C152-0.3.0.bin`: merged C152 image for offset `0x0`.
- `TokenLink-StopWatch-C152-0.3.0.zip`, `firmware-manifest.json`, and
  `SHA256SUMS`: split flash inputs, metadata, licenses, and checksums.

## Hands-on acceptance

1. Review Overview, Trends, Attribution, and Costs with several time ranges and
   metrics.
2. Refresh twice and confirm unchanged history files are reused.
3. Confirm Finder and both menu-bar icon surfaces match the canonical brand.
4. Bind a previously prepared C152 from a new Mac and verify quota sync becomes
   ready independently of Session command notification setup.
5. Install the published build through the Homebrew tap and follow the explicit
   community first-launch notice when the release is not notarized.
