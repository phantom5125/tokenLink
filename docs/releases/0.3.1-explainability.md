# TokenLink 0.3.1 — Cost calculation details

This independently mergeable v0.3.1 change makes every local
Estimated/API-equivalent total reviewable from the Costs card.

## What users can inspect

- Expand **How this estimate is calculated** on a local estimate card.
- Each priced model shows its subtotal, record count, and number of records
  that used request-level long-context pricing.
- Uncached input, cache read, cache write, and output show their token counts,
  exact category amounts, and blended effective rates per million tokens.
- The reviewed catalog rates, long-context threshold and multipliers, catalog
  version/effective date, and HTTPS pricing source are all visible.
- Locally observed unpriced model IDs are named under **Excluded unpriced
  models** and explicitly described as absent from the displayed total.

## Calculation integrity

Records continue to be priced before aggregation. Category amounts retain the
exact per-request multiplier result; an effective rate is derived only after
those amounts are summed. This avoids incorrectly applying a long-context
multiplier to an entire seven-day aggregate.

No prompt, response, transcript path, event identifier, monetary total, or
model detail is added to exported diagnostics. Pricing-source links open only
after an explicit user click.

## Verification

- 234 Swift tests pass, with expanded assertions for four independent token
  categories, long-context effective rates, aggregation, canonical price
  provenance, and excluded-model behavior.
- Strict Swift formatting and the privacy scan pass.
