# TokenLink 0.2.0 — Release Notes Draft

TokenLink 0.2 turns the Mac menu bar and M5Stack StopWatch C152 into one local
coding-plan surface.

## Highlights

- Four round-safe watch pages: Home, Quota, Sessions, and System.
- Codex, Claude, Kimi, MiniMax, and GLM quota in one native Mac app.
- Matching provider marks and quota bars on Mac and watch.
- Latest Codex task, aggregate active-task count, and up to three visible task
  rows on the watch.
- Tap-to-focus opens the matching Codex task on the Mac, with a compatibility
  activation fallback.
- Negotiated protocol v2 with byte-compatible protocol-v1 fallback.
- Configurable provider selection, theme, wake mode, and 12/24-hour time.
- Versioned, checksummed Mac archive with bundled resources and distribution
  notices.

## Assets to publish

- `TokenLink-0.2.0-macos-arm64.zip`
- `TokenLink-0.2.0-macos-arm64.zip.sha256`
- An `x86_64` or universal archive if Intel support is advertised for downloads.
- A link to the exact compatible `codex-micro-stopwatch` v0.2 source tag and its
  C152 installation/recovery instructions.

The public Mac archives must be Developer ID signed, Apple-notarized, and
stapled. CI development artifacts are ad-hoc signed and must not be relabeled as
the default public download.

## Known release gates

- Flash and observe the exact final C152 firmware candidate, including compact
  Home layout, full active count, provider cards, refresh, focus, and circular
  safe-area behavior.
- Complete the planned 24-hour power/wake/reconnect soak.
- Observe hosted CI on both final source revisions.
