# TokenLink 0.3.0 RC 1

TokenLink 0.3.0 turns the Mac Cost Center into a broader local Usage & Cost
workspace. This prerelease is intended for review on its own branch; it is not
merged into `main`.

## Highlights

- Attributes local Codex, Claude, and Kimi usage by project, model, reasoning
  effort, and privacy-safe Session. Project labels keep only the final directory
  component, while project and Session identifiers are hashed before storage.
- Adds a GitHub-style local-day activity calendar whose intensity can represent
  Token usage, API-equivalent cost, or estimated active time.
- Adds hourly distribution and time-series views with the current period overlaid
  against the immediately preceding equal-length period. Calendar-day alignment
  is preserved across daylight-saving changes.
- Adds custom date ranges within a 400-day local retention window.
- Estimates active time per Session: the first or isolated event contributes one
  minute, and consecutive gaps up to five minutes are counted. Concurrent
  Sessions may overlap, so the dashboard labels this as an estimate.
- Keeps exact Token, API-equivalent cost, and active-time values visible while
  ranking each attribution dimension by the selected metric.
- Shows Token-based cache reuse, input/output splits, project/model/Session
  counts, prior-period deltas, and API-equivalent pricing coverage.

## Local history and privacy boundary

- The first refresh parses supported local JSONL records; later refreshes reuse
  unchanged files and reparse only files whose size or modification time changed.
- History is bounded to 400 days, 250,000 retained events overall, and 75,000
  events per source file. Files over 256 MiB and records over 1 MiB retain the
  existing fail-closed scan behavior.
- The owner-only atomic JSON store contains normalized counters, timestamps,
  provider/model identifiers, sanitized project labels, and hashed attribution
  identifiers. It never stores prompts, replies, tool output, full paths, raw
  Session IDs, or raw Claude message IDs.
- API-equivalent cost is an estimate based on the reviewed bundled catalog, not
  a subscription invoice. The UI exposes the percentage of Token usage covered
  by known prices instead of treating unknown models as free.

## Review checklist

1. Enable the existing Costs beta and open **Usage & Cost**.
2. On **Overview**, switch Token / Cost / Active and verify the calendar changes
   metric while the KPI cards and pricing coverage remain understandable.
3. Switch among 7D, 30D, 90D, 1Y, and Custom; confirm both custom dates stay
   between the retained-history boundary and today.
4. On **Trends**, compare the current line/bars with the dashed previous-period
   series and verify the local-hour distribution.
5. On **Attribution**, switch Project / Model / Effort / Session and confirm the
   ranking follows the selected metric while exact Token, cost, and active time
   remain visible.
6. Refresh twice: the local-history card should report reparsed files on the
   first pass and reused files on the second pass when source files are unchanged.
7. Confirm the existing **Costs** section still separates authoritative provider
   balances from local API-equivalent estimates.

## Assets

- `TokenLink-0.3.0.dmg` and `.dmg.sha256`: Universal 2 Mac development build
  with the Applications shortcut.
- `TokenLink-StopWatch-C152-0.3.0.bin`: merged C152 image, flashed at offset
  `0x0` only after confirming the exact M5Stack StopWatch device port.
- `TokenLink-StopWatch-C152-0.3.0.zip`: split flash inputs, ELF, partition table,
  licenses, and image manifest.
- `firmware-manifest.json` and `SHA256SUMS`: release metadata and checksums for
  the firmware assets.

## Prerelease boundary

The Mac DMG attached to this RC is ad-hoc signed for development review. It is
not Developer ID signed, Apple-notarized, or a stable default download. The C152
firmware carries matching 0.3.0 version metadata but introduces no watch protocol
or face behavior change relative to the 0.2.3 candidate.
