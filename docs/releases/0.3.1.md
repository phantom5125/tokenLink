# TokenLink 0.3.1 — Costs periods

TokenLink 0.3.1 makes the Costs beta easier to read across useful time windows
without increasing local transcript access.

## What users see

- A persistent capsule control switches the Costs screen between **Today**,
  **Week**, and **Month**.
- Today means the current local calendar day. Week and Month mean trailing
  seven- and 30-calendar-day windows, including today.
- The selected period also controls a local Estimated/API-equivalent menu-bar
  supplement. Its compact unit changes between `today`, `7d`, and `30d`.
- Official provider spend displays the matching daily, weekly, or monthly value
  when the API supplies it. Balances remain visible and are never inferred.

## Local access and caching

- Refreshing a local estimate performs one bounded pass beginning at the
  30-day window start. Each normalized event is priced once and accumulated
  into every matching window.
- All three results are held in memory with independent freshness state.
  Switching the control only changes the presented cached snapshot; it does
  not read session files again.
- The period choice is saved in TokenLink configuration. Monetary totals and
  transcript-derived usage remain memory-only.

## Verification

- 237 Swift tests pass, including calendar boundaries, distinct Today / Week /
  Month totals, configuration migration, and a regression proving that two
  period changes retain a single loader call.
- Strict Swift formatting and the privacy scan pass.
