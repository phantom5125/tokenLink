# TokenLink 0.3.0 RC 2

TokenLink 0.3.0 RC 2 supersedes RC 1 for review. It keeps the local Usage & Cost
analytics scope and fixes three release-blocking distribution and onboarding
problems. The branch remains separate from `main`.

## Fixed in RC 2

- All shipped Mac icon surfaces now use the official
  `assets/branding/logo-mark-light.png` artwork. Finder, the menu-bar label, the
  menu panel, notifications, and ICNS packaging no longer use a separately
  drawn heavy-stroke mark.
- The App and provider SwiftPM bundles remain in the standard macOS
  `Contents/Resources` location. Production resource loading resolves that
  location before the generated `Bundle.module` accessor can fall back to a CI
  build path.
- The release builder mounts the finished DMG, verifies that its 1024 px ICNS
  frame exactly matches the canonical branding asset, and cold-starts the
  executable. A `could not load resource bundle` crash now fails the build.
- Discovering the C02 quota characteristic now makes the connection ready for
  sync immediately. C04 notifications continue enabling asynchronously, so an
  optional Session focus/refresh channel cannot strand a new user at
  “Connecting” before pairing begins.
- Matching RC 2 firmware increments the one-time GATT migration revision and
  removes older bonds on first boot. This is intended for watches that were
  prepared or tested on another Mac before being handed to a new user.

## Review checklist

1. Remove RC 1, drag `TokenLink.app` from the RC 2 DMG into Applications, and
   launch it without copying any `.bundle` directories by hand.
2. Compare Finder, menu-bar, and menu-panel icons with
   `assets/branding/logo-mark-light.png`; they should use the same thin open arc
   and infinity artwork.
3. Flash the RC 2 C152 image and reboot once. The firmware intentionally clears
   pre-RC2 Bluetooth bonds during this first boot.
4. On a Mac that has not previously bound this watch, discover and select it.
   Confirm the UI leaves “Connecting”, macOS completes its pairing flow, and a
   quota payload appears on the watch.
5. In StopWatch diagnostics, verify quota sync can be ready even if C04 command
   notifications are still pending. Once C04 becomes active, test Session focus
   separately.
6. Reopen Usage & Cost and repeat the RC 1 multidimensional attribution,
   calendar, trend, comparison, active-time, and custom-range checks.

## Assets and boundary

- `TokenLink-0.3.0.dmg` and `.dmg.sha256`: Universal 2, ad-hoc-signed Mac review
  build with an Applications shortcut and mounted-image cold-start validation.
- `TokenLink-StopWatch-C152-0.3.0.bin`: merged RC 2 C152 image, flashed at offset
  `0x0` only after confirming the exact M5Stack StopWatch device port.
- `TokenLink-StopWatch-C152-0.3.0.zip`, `firmware-manifest.json`, and
  `SHA256SUMS`: split images, metadata, licenses, and checksums.

This is a prerelease and is not Developer ID signed, Apple-notarized, merged
into `main`, or promoted as the stable default download.
